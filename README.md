# SmartServe

## Team Name
SmartServe

## Tech Stack
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Supabase-ready authentication
- Vitest

## User Stories Completed
- Bronze: Futuristic, intuitive restaurant experience with live menu and operations overview
- Silver: Secure authentication flow with role-based access plus digitized reservations, menu availability, and order handling
- Gold: Management dashboard for orders, reservations, inventory, and staff visibility
- Platinum: Intelligent operational insights with demand signals, queue awareness, and inventory visibility

## AI Usage
No external AI APIs were required for this prototype. The experience focuses on a realistic SaaS-style workflow demo.
